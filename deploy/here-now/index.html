LangGraph + FAISS + Tavily + Streamlit

Multi-Agent AI Deep Researcher

A research assistant for multi-hop, multi-source investigations. It coordinates retrieval, validation, analysis, reproducible snippets, insight generation, and report building through specialized agents.

Run locally View workflow

here.now hosts this static project page. The full Python Streamlit app runs on your machine or another compute host.

Contextual Retriever

Runs parallel Tavily searches across papers, news, reports, APIs, uploaded files, and FAISS top-k retrieval.

Tuning to Relevant Context

Summarizes all source signals and the top FAISS chunks before the Top 3 context is handed to downstream LLM agents.

Critical Analysis

Produces concise evidence-backed synthesis, contradictions, and source validation with configurable word limits.

Reproducible Snippet

Generates notebook-ready Python for source counts and evidence checklists from the retrieved context.

Report Builder

Builds a 200-300 word rules-checked report with source links and a human senior-engineer tone.

Simple workflow

  1. User research question enters the Streamlit UI.
  2. Query Planning Agent creates focused sub-questions.
  3. Contextual Retriever Agent starts parallel source lanes: research papers, news, reports, APIs, uploaded documents, and FAISS top-k.
  4. Tuning to Relevant Context combines all signals.
  5. Top 3 context is sent to Source Validator and LLM agents.
  6. Critical Analysis and Insight Generation produce concise findings.
  7. Reproducible Snippet Agent creates notebook-ready Python.
  8. Report Builder compiles the final structured report.

Run the full app

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
streamlit run streamlit_app.py

OpenRouter is supported through the API provider dropdown, or with: 

LLM_PROVIDER=openrouter
OPENAI_BASE_URL=https://openrouter.ai/api/v1
OPENAI_MODEL=openai/gpt-4o-mini
